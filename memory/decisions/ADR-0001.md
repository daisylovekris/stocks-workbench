# ADR-0001: Memory navigation only

## Status

- `ID`: `ADR-0001`
- `title`: `Memory navigation only`
- `status`: `proposed`

## Decision basis

`decision_basis: pending_owner_decision`

## Scope

`scope: project`

## Date

`date: 2026-07-29`

## Context

Rules, facts, reviews, cards, weekly observations, indexes, and closures already retain their own authority classes.

## Decision

Project Memory is a navigation layer over repository evidence and is not an authority source.

## Alternatives

Treat Memory as authoritative; duplicate source content into Memory; retain navigation-only references.

## Consequences

Memory stays small and auditable, while every material claim must retain an exact source identity.

## Authority boundaries

Grants no permission, fact, business-state, trading, Git, or review authority.
