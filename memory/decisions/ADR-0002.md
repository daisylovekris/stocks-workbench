# ADR-0002: Repository and runtime separation

## Date

`date: 2026-07-29`

## Context

Local sessions, caches, credentials, and runtime manifests are machine-specific and may contain sensitive or non-portable state.

## Decision

Portable repository Memory may describe runtime identities but does not copy or depend on external runtime state.

## Alternatives

Merge runtime state into the repository; link absolute runtime paths; retain a repository/runtime boundary.

## Consequences

Repository artifacts remain portable; missing runtime evidence fails closed instead of being inferred.

## Authority boundaries

Runtime state cannot replace repository evidence and absolute local paths are forbidden in formal records.
