# ADR-0005: No future-data leakage

## Date

`date: 2026-07-29`

## Context

Later data can make a historical result appear stronger and silently change the meaning of a dated artifact.

## Decision

Dated analyses and validations must be bound to their stated cutoff and may not import later observations.

## Alternatives

Use latest data for every refresh; omit cutoffs; retain explicit time-bounded evidence.

## Consequences

Historical statements remain reproducible and later evidence is recorded separately.

## Authority boundaries

Time-bounded evidence does not itself create a trading conclusion or action trigger.
