## 一、核心功能

serenity-skill 是一个 AI Agent Skill，采用结构化的产业链瓶颈研究方法论，用于股票和基金筛选。

核心管道：

```
市场热点主题 → 真实需求信号识别 → 产业链分层拆解 → 瓶颈环节识别 → 公司筛选 → 证据验证 → 风险评估 → 优先级排序
```

关键能力：

- 将热点主题拆解为真实需求信号
- 按层级映射产业链（下游需求 → 系统集成 → 芯片/组件 → 设备 → 材料 → 封测 → 基础设施）
- 识别"供应商少、验证周期长、扩产难"的供应链瓶颈
- 挑战公司是否真正受益还是只是蹭热点
- 用公告、财报、问询函、订单、产能、客户、风险进行验证
- 产出优先级排序的研究清单（个股 + 基金/ETF 方向）

## 二、产业链瓶颈研究方法论

### 核心原则

在大级别行情中，最有价值的机会往往藏在系统扩张时最难绕开的关键环节。

### 研究路径

1. 从热点主题出发，识别真实需求在哪里
2. 将主题拆解为产业链层级
3. 找出最难扩产或最难替代的环节
4. 回到个股和基金方向，评估谁最接近真实瓶颈，谁只是蹭主题
5. 用公告、财报、问询函、订单、产能、客户、风险因素验证
6. 产出优先级排序

### 产业链分层

| 层级 | 说明 |
|------|------|
| 下游需求 | 真实终端需求所在 |
| 系统集成 | 组装商和集成商 |
| 芯片/组件 | 半导体和关键组件供应商 |
| 设备 | 制造设备供应商 |
| 材料 | 上游材料供应商 |
| 封测 | 后道工序服务 |
| 基础设施 | 电力、冷却、设施 |

### 瓶颈识别标准

| 特征 | 说明 |
|------|------|
| 供应商数量少 | 只有少数公司能供应该组件 |
| 验证周期长 | 客户需要较长时间认证新供应商 |
| 扩产困难 | 产能爬坡缓慢或资本密集 |
| 客户认证严格 | 进入壁垒高 |
| 材料纯度要求高 | 技术护城河深 |

## 三、证据链方法论

项目引用了"证据阶梯"体系（`references/evidence-ladder.md`）。

### 证据层级（从强到弱）

| 层级 | 来源 |
|------|------|
| 最强 | 公司公告、交易所文件 |
| 强 | 财报、业绩说明会 |
| 中 | 监管/项目文件、专利、标准 |
| 较弱 | 权威媒体、专业分析 |
| 线索 | 社交媒体（只能作为线索，不能作为结论依据） |

### 核心规则

- 每个公司评估必须回到公告、交易所文件、财报等权威来源
- 社交媒体内容定位为"线索源"
- 证据不足时必须明确标注，并指出什么信息会改变评估

**非常适合。**

| 维度 | 评估 |
|------|------|
| A 股热点主题 | ✅ 设计目标就是 A 股热点主题（AI 半导体、机器人、CPO、算力） |
| 产业链拆解 | ✅ 按层级拆解，适合 A 股产业链研究 |
| 瓶颈识别 | ✅ 适合识别 A 股产业链中的关键环节 |
| 候选股筛选 | ✅ 产出优先级排序的个股清单 |
| 基金/ETF 方向 | ✅ 评估主题基金的真实暴露 |
| 证据验证 | ✅ 强调回到公告、财报、问询函 |
| 示例 | ✅ 含 A 股 AI 半导体示例、AI 基础设施瓶颈示例 |

## 五、是否适合周日"下周走势与主题观察"

**适合。**

可以用于：

- 每周梳理当前市场热点主题
- 拆解主题产业链
- 识别本周哪些环节有新催化
- 评估哪些方向值得下周重点观察
- 排除已经过度叙事的方向
- 产出下周重点观察清单

输出模板：

```
下周观察｜YYYY-MM-DD

一、本周主题回顾
二、产业链拆解
三、瓶颈环节识别
四、重点观察方向（按优先级排序）
五、需要验证的证据
六、风险提示
七、排除方向（为什么不在观察清单）
```

## 七、哪些部分可借鉴

### 1. 产业链拆解

将热点主题按层级拆解（下游需求 → 系统集成 → 芯片/组件 → 设备 → 材料 → 封测 → 基础设施），适合用于：

- 阳光电源所处储能/电力设备产业链
- 合盛硅业所在硅材料/周期链条
- 西藏矿业所在盐湖提锂/资源链条

### 2. 供应链瓶颈识别

"供应商少、验证周期长、扩产难"的瓶颈识别标准，适合用于：

- 逆变器行业竞争格局分析
- 储能系统集成中的关键组件
- 海外订单履约中的瓶颈环节

### 3. 证据链

"证据阶梯"体系（公告 > 财报 > 监管文件 > 媒体 > 社交媒体），适合用于：

- 强化小工坊的信息验证流程
- 与 Perplexity 交叉验证配合
- 复盘时的证据评估

### 4. 风险边界

"研究支持，交易归用户"原则，与小工坊"不做自动交易"一致。

### 5. 候选股/基金方向优先级排序

按产业链位置 + 证据强度 + 估值压力 + 风险排序，适合用于：

- 周日"下周走势与主题观察"
- 主题方向拆解
- 候选股池筛选

## 十、风险点

| 风险 | 等级 | 说明 |
|------|------|------|
| **热点主题过度叙事** | 🟡 中 | 热点主题容易被市场过度炒作，产业链拆解也可能被叙事裹挟 |
| **AI 把"瓶颈"说得过于确定** | 🟡 中 | AI 可能把某些环节描述为"确定性瓶颈"，但实际情况可能更复杂 |
| **需要回到公告/财报验证** | 🟡 中 | 产业链分析只是框架，最终判断必须回到公告、财报、订单、客户、产能验证 |
| **不可替代估值和仓位纪律** | 🟡 中 | 产业链研究不能替代估值判断和仓位管理 |
| **主题轮动快** | 🟡 中 | A 股主题轮动快，本周的瓶颈下周可能被证伪 |
| **无交易功能** | 🟢 低 | 纯研究工具，无交易能力 |

## 十一、结论

**评级：只读参考 + 可借鉴方法论**

理由：

1. **产业链瓶颈研究方法论对小工坊有直接价值。** 可以补充深研框架中的行业与竞争格局分析，强化自上而下的主题研究能力。
2. **证据链体系与小工坊信息验证流程一致。** "证据阶梯"可以强化复盘和研究中的证据评估。
3. **适合周日"下周走势与主题观察"。** 产业链拆解 + 主题梳理 + 优先级排序，最匹配周末研究场景。
4. **适合阳光电源储能产业链复核。** 可以用瓶颈识别方法重新审视储能系统中的关键环节。
5. **不需要安装为 Agent Skill。** 方法论可以直接借鉴，不需要复制到 .claude/skills 目录。

建议态度：

- ✅ 借鉴其产业链拆解方法论，写入小工坊方法论文件
- ✅ 借鉴其证据链体系，强化信息验证流程
- ✅ 用于周日"下周走势与主题观察"模板
- ✅ 用于阳光电源储能产业链复核
- ✅ 用于合盛硅业/西藏矿业周期链条复核
- ❌ 不安装为 Agent Skill
- ❌ 不运行本地脚本评分
- ❌ 不启用自动交易功能

## 十二、后续使用方案：方法论文件 / 周报模板

**前提：** 只借鉴方法论，不安装 skill、不运行脚本、不自动生成交易方向。

### 方案 A：产业链拆解方法论文件

创建 `rules/industry_chain_analysis_v0.1.md`，内容包括：

1. 产业链分层框架（下游需求 → 系统集成 → 组件 → 设备 → 材料 → 基础设施）
2. 瓶颈识别标准（供应商少、验证周期长、扩产难、客户认证严格）
3. 证据链体系（公告 > 财报 > 监管文件 > 媒体 > 社交媒体）
4. 热点主题拆解流程
5. 候选股优先级排序方法
6. 风险边界（研究支持，交易归用户）

### 方案 B：周日"下周走势与主题观察"模板

创建模板文件，内容包括：

```
下周观察｜YYYY-MM-DD

一、本周市场主题回顾
  - 本周有哪些热点主题？
  - 哪些主题有真实催化？
  - 哪些主题已经过度叙事？

二、产业链拆解
  - 热点主题的产业链分层
  - 各层级的供需紧张度
  - 竞争格局

三、瓶颈环节识别
  - 哪些环节最难扩产？
  - 哪些环节供应商最少？
  - 哪些环节验证周期最长？

四、重点观察方向（按优先级排序）
  - 方向 1：...
  - 方向 2：...
  - 方向 3：...

五、需要验证的证据
  - 需要查看的公告/财报
  - 需要确认的订单/产能
  - 需要跟踪的资金面

六、风险提示
  - 哪些方向可能被证伪？
  - 哪些方向估值已经偏高？

七、排除方向
  - 为什么不在观察清单？
```
