# 股票小工坊规则索引

## 一、规则索引定位

本文件是股票小工坊的小工开工入口。

后续 Codex / CC / OpenCode / MiMo Code 等工具在更新股票小工坊前，应先阅读本索引，并根据任务类型阅读对应规则文件。

股票小工坊不是自动交易系统，也不是买卖建议系统。

本项目当前定位：

- 持仓观察；
- 日复盘；
- 周观察计划；
- 风险识别；
- 估值与安全边际观察；
- 加仓评估条件分析；
- 工具与数据源辅助校验。

禁止：

- 自动交易；
- 输出即时买卖建议；
- 把观察条件写成执行动作；
- 让工具接管仓位纪律。

## 二、当前生效规则

### 1. 复盘链路连续文档更新规则

文件：

- `rules/review_chain_update_rules_v0.1.md`

用途：

用于约束日复盘、总索引、低位观察卡、持仓卡、风险卡、估值卡、加仓分析卡等连续演化文档的更新方式。

核心要求：

- 新增日期小节不等于完成更新；
- 必须同步当前状态、当前结论、底部本卡结论；
- 必须扫描中段长期框架、条件区、触发区、操作影响区、小标题；
- 历史小节保留，当前判断必须升级到最新交易日；
- 盘中突破、收盘站上、连续维持必须严格区分；
- 观察条件不得写成买卖动作；
- git 前必须做全链只读审计。

适用任务：

- 新增每日复盘；
- 同步卡组；
- 更新总索引；
- 修正连续文档旧口径残留；
- 做 git 前全链审计。

### 2. 自动化总蓝图

文件：

- `rules/automation_architecture_v0.1.md`

用途：

股票小工坊自动化总蓝图：事实包、价位身份、校验器、封箱检查、小工权限边界与预测参考层规则。

核心要求：

- 先做事实包、价位身份和校验器，再谈后续施工；
- 封箱检查必须覆盖 staged / untracked / rename 半状态；
- 小工权限边界必须清楚，禁止越权修改和自动交易；
- 预测工具只放参考层，不进主链。

适用任务：

- 规划自动化蓝图；
- 施工 Phase 1 脚本；
- 校验自动化闸门；
- 约束小工权限边界。

## 三、工具与数据源边界

### 1. 行情 / 技术快照工具

相关文件或目录：

- `tools/`
- `repo_screening/daily_stock_analysis_fit_summary_2026-07-01.md`

定位：

行情、技术面、实时快照、成本摊薄计算等工具只能作为数据层或辅助观察层。

可以用于：

- 实时价快照；
- 高低点；
- 成交额 / 量比 / 换手；
- 技术指标；
- 成本摊薄计算；
- 多票巡检；
- 盘后摘要输入。

不能用于：

- 最终加仓决策；
- 基本面定案；
- 公告级重大利好 / 利空定案；
- 自动交易执行；
- 替代风险卡、估值卡、加仓分析卡。

特别规则：

成本摊薄计算只能说明“补仓后平均成本会变成多少”，不能自动推出“应该补仓”。

## 四、小工开工前必读

不同任务应先阅读：

### 1. 更新日复盘 / 卡组

必读：

- `rules/README.md`
- `rules/review_chain_update_rules_v0.1.md`
- `stock_workbench_index.md`
- 最近 1—3 篇日复盘
- 相关卡片当前版本

### 2. 修改规则文件

必读：

- `rules/README.md`
- 目标规则文件全文
- `stock_workbench_index.md` 中相关入口

### 3. 引入新工具 / 新仓库

必读：

- `rules/README.md`
- `repo_screening/` 中对应适配总结
- 工具自身 README / requirements / 脚本说明

原则：

先做只读盘点和适配总结，不直接接入主链，不自动修改正式复盘文件。

## 六、强制边界

任何小工不得：

- 读取 `.env`、token、key、secret；
- 擅自 git add / commit / push；
- force push；
- 修改任务未指定文件；
- 输出即时买卖建议；
- 把观察条件写成买卖动作；
- 把 150 / 145 / 138.61 写成硬底；
- 把盘中突破写成收盘确认；
- 把风险缓和写成风险解除；
- 把加仓评估改善写成加仓条件成熟。
