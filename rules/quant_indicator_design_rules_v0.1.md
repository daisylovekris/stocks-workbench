# 量化指标设计规则｜quant_indicator_design_rules_v0.1

## 一、定位

本文件规定股票小工坊引入量化观察指标时的设计原则。

核心原则：

量化指标只用于观察、复核和描述，不用于自动交易，不生成买卖指令。

## 二、基本边界

所有指标必须满足：

- 可解释；
- 可复核；
- 可人工确认；
- 可回看历史；
- 不依赖黑箱模型；
- 不绕过公告、资金、板块和大盘环境；
- 不直接触发交易动作。

所有指标不得：

- 自动下单；
- 自动补仓；
- 自动清仓；
- 自动判断买卖点；
- 把历史概率当未来保证；
- 用单一指标替代完整复盘；
- 用复杂公式制造虚假确定性。

## 三、第一批可用观察指标

### 1. 波动率观察

用途：

- 判断当日波动是否明显放大；
- 判断关键价位被触碰时是否伴随高波动；
- 判断冲高回落是否属于异常波动。

初步观察项：

- 当日振幅；
- 近 5 日平均振幅；
- 当日振幅是否高于近 5 日均值；
- 高波动后是否延续；
- 高波动后是否回到原区间。

### 2. 均值回归观察

用途：

- 判断跌破关键位后是否快速收回；
- 判断反弹是否只是回到原区间；
- 判断"假跌破 / 假突破"的可能性。

初步观察项：

- 跌破 145 后几日内是否收回；
- 触碰 150 后是否回落到 145—150；
- 冲高 153—155 后是否回落；
- 高波动日后是否回到近 5 日均值附近。

### 3. 动量观察

用途：

- 判断上涨或下跌是否具备延续性；
- 判断放量上涨是否得到次日确认；
- 判断反弹是否只是单日试攻。

初步观察项：

- 连续上涨天数；
- 连续下跌天数；
- 放量上涨后次日表现；
- 放量冲高回落后次日表现；
- 收盘是否继续站在关键位上方。

### 4. 量价配合观察

用途：

- 判断"放量试攻""缩量整理""放量下跌"等复盘口径是否有数据支撑。

初步观察项：

- 今日成交额 / 近 5 日平均成交额；
- 今日量比；
- 涨跌幅与成交额是否匹配；
- 收盘位置是否靠近全天高点；
- 放量后是否收在关键位上方；
- 放量后是否冲高回落。

### 5. 相对强弱观察

用途：

- 判断个股是否强于或弱于大盘、创业板、新能源链。

初步观察项：

- 个股涨跌幅 vs 大盘；
- 个股涨跌幅 vs 创业板；
- 个股涨跌幅 vs 新能源 / 储能 / 光伏设备板块；
- 板块飘红但个股弱跟随；
- 大盘回落但个股抗跌；
- 个股是否连续弱于板块。

### 6. 回撤与风险暴露观察

用途：

- 判断当前持仓风险是否扩大；
- 判断价格距离成本、防线和心理锚的状态。

初步观察项：

- 当前价距成本价 181 的幅度；
- 当前浮亏幅度；
- 当前价距 145 防线的距离；
- 当前价距 138.61 员工持股均价心理锚的距离；
- 近阶段最大回撤；
- 连续弱于板块时的风险暴露。

## 四、日复盘使用方式

每日复盘中，量化观察只能作为辅助小节。

建议格式：

## 量化观察标签

- 波动率：正常 / 放大 / 明显放大；
- 均值回归：无 / 低位回归 / 高位回落；
- 动量：未确认 / 弱延续 / 强延续；
- 量价配合：缩量整理 / 放量试攻 / 放量下跌 / 放量回落；
- 相对强弱：强于板块 / 跟随板块 / 弱于板块；
- 风险暴露：缓和 / 未变 / 加重。

注意：

- 标签必须有行情数据支撑；
- 标签不能替代复盘结论；
- 标签不能写成买卖建议。

## 五、周六股性研究使用方式

周六不做日复盘时，可做阳光电源股性研究专题。

优先研究：

- 放量试攻后的次日表现；
- 冲高回落后的三日表现；
- 跌破关键位后的收回情况；
- 150 / 153—155 / 145 等关键位历史表现；
- 高波动日后的量能变化；
- 阳光电源更偏趋势延续，还是高波动均值回归；
- 弱于板块是否会延续；
- 强于板块是否有后续确认。

边界：

- 只做历史统计；
- 不输出交易指令；
- 不把样本规律当未来保证；
- 样本不足时必须标注"不足以判断"；
- 与当日公告、资金面、板块、大盘环境分开记录。

## 六、当前禁区

暂不引入：

- 高频指标；
- 分钟级交易信号；
- tick 数据；
- 自动择时；
- 机器学习预测价格；
- 强化学习策略；
- 实盘交易机器人；
- 复杂期权模型；
- 无法解释的黑箱因子。

## 七、当前结论

小工坊第一阶段只吸收轻量量化观察。

目标不是"预测未来"，而是：

- 让复盘语言更清晰；
- 让价位判断更有依据；
- 让风险描述更可回看；
- 让周六股性研究有素材；
- 让日常纪律更扎实。
