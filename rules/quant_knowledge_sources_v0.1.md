# 量化知识源｜quant_knowledge_sources_v0.1

## 一、定位

本文件记录股票小工坊可参考的量化知识源。

当前首个知识源：

- 名称：awesome-quant-interview
- 来源：GitHub 仓库 SoYuCry/awesome-quant-interview
- 原始用途：量化研究 / Alpha Research / QR 面试准备
- 小工坊用途：量化研究地图、方法论索引、工具候选池、指标设计参考
- 小工坊不用途：自动交易、实盘下单、策略黑箱化、买卖指令生成

## 二、为什么纳入小工坊

该知识源虽以量化求职为入口，但内容覆盖：

- Python / Pandas / NumPy
- 数据清洗与数据工程
- 时间序列分析
- 统计学基础
- 波动率
- 均值回归
- 动量因子
- Alpha 因子
- 回测框架
- 风险控制
- 组合优化
- 量化工具生态
- AI + Finance
- 研报复现
- 面试题与知识结构

对股票小工坊的价值不在于"立刻做量化交易"，而在于：

- 建立量化研究地图；
- 规范指标语言；
- 提升数据质检能力；
- 改进日复盘与周观察的观察维度；
- 为周六股性研究提供概念框架。

## 三、小工坊吸收原则

当前只吸收以下内容：

- 数据质检；
- 字段统一；
- 缺失值检查；
- 异常值标记；
- 双源行情校验；
- 波动率观察；
- 均值回归观察；
- 动量观察；
- 量价配合观察；
- 相对强弱观察；
- 回撤与风险暴露观察。

当前不吸收以下内容：

- 高频交易；
- 做市系统；
- 自动下单；
- 复杂期权定价；
- 随机微积分推导；
- C++ 低延迟架构；
- 强化学习实盘；
- 实盘机器人；
- 面试智力题。

## 四、与股票小工坊当前流程的关系

当前小工坊已有流程：

- 工作日每日复盘；
- 周日下周观察；
- 周六股性研究；
- 行情源优先 AKShare；
- 腾讯行情 API 作为备用与交叉验证；
- 同花顺人工补充量比；
- Perplexity 只做公告、新闻、行业、资金面交叉验证；
- 所有重要更新完成后进入 git commit + GitHub 私库留痕。

量化知识源进入后，只增强以下层面：

- 数据质量；
- 观察标签；
- 复盘口径；
- 周度纪律；
- 股性研究。

不得改变以下边界：

- 不自动交易；
- 不生成买卖指令；
- 不绕过人工确认；
- 不以工具替代判断；
- 不因历史统计而忽略当日公告、资金、板块、市场环境。
