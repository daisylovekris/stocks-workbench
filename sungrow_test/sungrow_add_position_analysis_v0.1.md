# 阳光电源加仓节点分析｜v0.1

## 一、本卡定位

本文件用于分析阳光电源在当前阶段“哪些位置值得重新评估加仓逻辑”，以及“哪些前提不满足时不应加仓”。

本卡只做分析，不输出即时买卖指令，不替代日复盘、风险卡、估值卡或持仓卡。

本卡的作用是：

- 把“加仓”从情绪冲动里拆出来；
- 把可观察区间、前提条件、否决条件写清楚；
- 让后续判断不被单日大涨或单日回撤带偏；
- 为以后可能的股性研究与历史统计预留接口。

## 二、当前背景

截至 2026-06-25，阳光电源经历了 06-22 强修复、06-23 高位回吐、06-24 缩量修复、06-25 弱修复未延续的四天波动：

- 06-22：节后放量强修复，收盘 163.46，涨幅 +11.21%，150、153—155、157 三层压力位被单日集中突破，收盘站上 160；
- 06-23：高位回吐，收盘 152.00，跌幅 -7.01%，160 与 157 失守，153—155 被重新跌回，150 成为近端防线；
- 06-24：缩量修复，收盘 154.80，涨幅 +1.84%，150 盘中失守后重新拉回，153—155 被重新收回，但 157 只是盘中触及（157.98），未确认站上，160 仍未收回；
- 06-25：弱修复未延续，收盘 152.66，跌幅 -1.38%，153—155 未能继续维持，157 未触及，150 再次盘中失守后收回，145—150 盘中已触及但收盘未正式留在区间内；
- 未见新增公告级重大利好或重大利空；
- 大盘、创业板红，但新能源 / 储能 / 光伏设备全绿；
- 板块全绿、资金承托偏弱，加仓评估条件没有改善。

当前加仓分析的主矛盾已经不是：

- 06-24 已经收回 153—155，是否可以评估加仓；

而是：

- 153—155 能否重新收回并连续维持；
- 150 是否还能反复收回，还是收盘正式跌回下方；
- 145—150 是否正式重回主战场；
- 板块全绿是否延续；
- 资金承托是否改善。

## 三、这张卡不解决什么问题

本卡不解决：

- 今天要不要立刻买；
- 明天开盘追不追；
- 盘中某一笔是否该下单；
- 自动化交易；
- 预测短期必涨或必跌。

本卡只解决：

- 哪些位置可以进入“重新评估加仓逻辑”；
- 哪些情况必须明确否决“加仓”；
- 哪些位置只是观察，不应自动推导为“加仓”；
- 哪些数据仍需补充。

## 四、当前不能直接加仓的情况

以下情况，不应仅因为价格变化就直接推导为「加仓」：

### 1. 不因为没有公告级重大利空，就判断加仓风险下降

- 06-25 未见新增公告级重大利空；
- 但没有利空不等于可以加仓；
- 不能把「没有坏消息」直接等同于「可以动手」。

### 2. 不因为收盘仍在 150 上方，就判断 150 已稳

- 06-25 收盘 152.66，仍在 150 上方；
- 但 06-23 最低 150.40，已经近距离考验 150；06-24 最低 149.22，盘中失守后收回；06-25 最低 149.63，再次盘中失守后收回；
- 不能把「收盘还在上面」直接理解成「150 已经稳住」。

### 3. 不因为 150 盘中失守后收回，就把 150 当作硬底

- 06-24 最低 149.22，盘中失守后收回；
- 06-25 最低 149.63，再次盘中失守后收回；
- 150 仍有近端防线意义，但防线质量需要验证；
- 不能把「又拉回来了」直接理解成「不会再破」。

### 4. 不因为 145—150 盘中已触及，就直接认为低位机会出现

- 06-25 盘中已触及 145—150；
- 但收盘 152.66，未正式留在区间内；
- 不能把「碰到了」直接等同于「可以抄底」。

### 5. 不因为 06-24 曾收回 153—155，就忽略 06-25 未能继续维持

- 06-24 收盘 154.80，153—155 已重新收回；
- 06-25 收盘 152.66，153—155 未能继续维持；
- 不能把「昨天收回了」直接等同于「今天仍然有效」。

### 6. 不因为中期叙事仍偏正面，就忽略当日板块全绿与资金承托偏弱

- 海外订单、储能业务、中东储能大单、AIDC 电源等仍偏正面；
- 但 06-25 新能源 / 储能 / 光伏设备全绿，资金承托偏弱；
- 不能把「故事还行」直接等同于「现在可以加」。

### 7. 新增公告级重大利空

包括但不限于：

- 业绩暴雷；
- 监管处罚；
- 重大诉讼；
- 大股东质押风险变化；
- GDR / 员工持股 / 股权激励异常；
- 海外订单、储能业务重大负面变化。

若出现以上情况，本卡需重新评估，不可沿用当前结论。

## 五、可以进入「重新评估加仓逻辑」的情况

注意：以下情况只是「进入重新评估区」，不是自动触发「加仓」。

### 1. 153—155 重新收回并连续维持

06-25 后，153—155 已从「已收回待维持」重新变成「待收回观察带」。若后续重新收回并连续维持，说明：

- 06-25 的二次回落被阶段性消化；
- 短线支撑重新尝试重建；
- 这是重新评估加仓逻辑的第一前提。

### 2. 150 不再反复盘中失守，且没有收盘正式跌回下方

06-24 与 06-25 均出现盘中失守后收回。说明 150 仍有近端防线意义，但防线质量需要验证。若后续不再反复盘中失守，且收盘不正式跌回 150 下方，才说明近端风险缓和。

### 3. 145—150 没有正式重回主战场

06-25 已盘中触及 145—150，但收盘未正式留在区间内。若后续收盘正式留在 145—150 内部，加仓评估应继续后移，不应前置。

### 4. 板块与资金承托改善

- 新能源 / 储能 / 光伏设备从全绿转为分化或一致修复；
- 成交额和量比改善；
- 个股在指数红时不再明显弱于板块；
- 主力资金或承接状态改善。

### 5. 157 重新被触及，但不能单独作为加仓条件

06-25 未触及 157。若后续重新触及 157，说明修复弹性有所恢复。但只有在 153—155 已重新收回并连续维持、量能与板块配合改善时，157 才能提高评估权重。

## 七、当前最值得观察的「重新评估区」

从当前阶段看，最值得观察的不是：

- 没有公告级利空就追着补；
- 也不是明显跌回旧弱势区间后情绪化抄底；

而是这三层：

### 第一优先：153—155 重新收回并连续维持

原因：

- 06-24 曾重新收回，06-25 未能继续维持；
- 当前 153—155 已重新成为待收回观察带；
- 若不能重新收回，修复评估不能前置；
- 这是当前最值得重视的观察窗口。

### 第二优先：150 不再反复盘中失守，且收盘不正式跌回下方

原因：

- 06-24 最低 149.22，盘中失守后收回；
- 06-25 最低 149.63，再次盘中失守后收回；
- 150 仍有近端防线意义，但防线质量下降；
- 必须区分「盘中失守后收回」和「收盘正式跌回」；
- 只有后续不再反复盘中失守，近端风险才缓和。

### 第三优先：145—150 是否正式重回主战场

原因：

- 06-25 已经盘中触及 145—150；
- 但收盘 152.66，未正式留在区间内；
- 若后续收盘正式留在 145—150 内部，说明结构重心进一步下移；
- 在这种情况下，加仓评估不应提前，反而要继续后移。

## 八、需要补充的数据

这张卡目前仍缺：

1. 主力资金多日连续性；
2. 融资融券日度变化；
3. 更长区间的量价样本；
4. 157、153—155 附近历史回踩质量；
5. 新能源 / 储能 / 光伏设备板块与个股相对强弱样本；
6. Q2 / Q3 利润修复情况；
7. 储能毛利率变化；
8. 海外订单兑现与现金流表现。

## 九、当前纪律

当前不做：

- 不因为单日大涨就追着加；
- 不因为价格离成本近了就自动降低标准；
- 不因为回踩不破某个价位就直接等同于“加仓”；
- 不因为价格重新回到旧区间就把它当成便宜；
- 不把员工持股均价当硬底；
- 不把分析卡写成即时指令；
- 不做自动交易。

## 十、本卡当前结论

2026-06-25 是 06-24 弱修复未延续后的二次回落。153—155 未能继续维持，157 未触及，160 未收回，150 再次盘中失守后收回，145—150 盘中已触及但收盘未正式留在区间内。今日未见新增公告级重大利空，但板块全绿、资金承托偏弱，说明加仓评估条件没有改善。

当前最值得观察的已经不是「153—155 是否继续维持」，而是「153—155 能否重新收回并连续维持」；也不是简单看「150 是否盘中跌破」，而是看「150 是否收盘正式跌回下方」；同时要观察 145—150 是否正式重回主战场。

在 153—155 未重新收回、150 防线质量未确认、板块与量能未改善之前，本卡只作为观察与评估工具，不输出即时买卖动作。当前结论是：加仓评估继续后移。
