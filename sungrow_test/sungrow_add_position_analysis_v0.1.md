# 阳光电源加仓节点分析｜v0.1

## 一、本卡定位

本文件用于分析阳光电源在当前阶段“哪些位置值得重新评估加仓逻辑”，以及“哪些前提不满足时不应加仓”。

本卡只做分析，不输出即时买卖指令，不替代日复盘、风险卡、估值卡或持仓卡。

本卡的作用是：

- 把“加仓”从情绪冲动里拆出来；
- 把可观察区间、前提条件、否决条件写清楚；
- 让后续判断不被单日大涨或单日回撤带偏；
- 为以后可能的股性研究与历史统计预留接口。

## 三、这张卡不解决什么问题

本卡不解决：

- 今天要不要立刻买；
- 明天开盘追不追；
- 盘中某一笔是否该下单；
- 自动化交易；
- 预测短期必涨或必跌。

本卡只解决：

- 哪些位置可以进入“重新评估加仓逻辑”；
- 哪些情况必须明确否决“加仓”；
- 哪些位置只是观察，不应自动推导为“加仓”；
- 哪些数据仍需补充。
