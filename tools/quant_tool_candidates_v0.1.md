# 量化工具候选池｜quant_tool_candidates_v0.1

## 一、定位

本文件记录股票小工坊未来可能评估的量化工具。

当前原则：

- 只列候选；
- 不立即安装；
- 不立即运行；
- 不连实盘；
- 不配置交易权限；
- 不生成自动交易能力；
- 所有工具先做用途评估，再决定是否小样本试验。

## 二、第一批候选工具

### 1. Pandas / NumPy

类型：

- Python 数据处理基础库。

小工坊用途：

- 日线数据清洗；
- 字段统一；
- 缺失值检查；
- 双源行情校验；
- 轻量指标计算。

适合程度：

- 高。

当前动作：

- 可作为 CC 数据质检能力的基础技能；
- 后续脚本若增加指标计算，优先用 Pandas / NumPy。

风险：

- 自动清洗可能误删异常行情；
- 所有异常值只能标记，不能自动删除。

### 2. Polars

类型：

- 高性能数据处理库。

小工坊用途：

- 未来大量历史行情数据处理；
- 批量股性研究；
- 多股票、多日期数据聚合。

适合程度：

- 中。

当前动作：

- 暂列候选；
- 当前 Pandas 已足够；
- 数据量明显增大后再评估。

风险：

- 过早引入会增加复杂度。

### 3. VectorBT

类型：

- 向量化回测与量化研究框架。

小工坊用途：

- 未来轻量回测；
- 形态统计；
- 参数扫描；
- 股性研究验证。

适合程度：

- 中高。

当前动作：

- 暂列候选；
- 不立刻安装；
- 周六股性研究成熟后再评估。

风险：

- 容易过早进入"策略优化"；
- 易产生过拟合；
- 不得用于自动交易。

### 4. Backtrader

类型：

- 事件驱动回测框架。

小工坊用途：

- 未来学习回测框架；
- 对比 VectorBT 的研究方式。

适合程度：

- 中。

当前动作：

- 暂列候选；
- 不作为第一批试验工具。

风险：

- 框架较重；
- 可能分散当前日复盘主线。

### 5. Qlib

类型：

- AI-oriented Quant investment platform。

小工坊用途：

- 远期研究平台候选；
- 理解量化研究工程化流程；
- 学习因子、模型、实验管理思路。

适合程度：

- 远期候选。

当前动作：

- 只观察，不安装；
- 不进入当前小工坊执行层。

风险：

- 系统重；
- 学习成本高；
- 可能把小工坊带偏成工具工程；
- 不适合当前日线人工复盘阶段。

### 6. cvxpy

类型：

- 凸优化 / 组合优化工具。

小工坊用途：

- 未来组合仓位、风险暴露、资金分配概念学习；
- 不用于自动调仓。

适合程度：

- 中。

当前动作：

- 暂列概念候选；
- 当前不启用。

风险：

- 容易把数学优化误当成实盘答案；
- 需要先有可靠收益、风险、相关性输入。

### 7. FinRL / FinGPT / FinRobot

类型：

- AI + Finance 研究工具。

小工坊用途：

- 观察 AI 金融研究生态；
- 学习金融文本、新闻、研报处理方式；
- 不作为交易系统。

适合程度：

- 观察候选。

当前动作：

- 只放入远期观察；
- 不安装；
- 不连交易；
- 不替代 Perplexity 交叉验证。

风险：

- 黑箱程度高；
- 容易生成貌似高级的预测；
- 不适合当前阶段使用。

### 8. RD-Agent

类型：

- AI research automation / 量化研究自动化候选。

小工坊用途：

- 远期观察；
- 了解论文、因子、实验自动化流程。

适合程度：

- 远期候选。

当前动作：

- 只观察；
- 不安装；
- 不运行；
- 不把因子自动生成结果写入复盘。

风险：

- 自动化程度过高；
- 易脱离小工坊当前人工审查原则。

## 三、当前不纳入工具

以下工具或方向暂不纳入：

- 高频交易框架；
- 做市系统；
- 自动下单机器人；
- 期权复杂定价工具；
- tick 级交易工具；
- C++ 低延迟架构；
- 强化学习实盘系统；
- 无法解释的黑箱策略平台。

## 四、工具进入小工坊的门槛

任何工具进入小工坊，必须经过四步：

1. 观察；
2. 评估；
3. 小样本验证；
4. 用户确认。

不得跳过：

- 不得从候选直接进入实盘；
- 不得从候选直接进入交易脚本；
- 不得自动写入买卖规则；
- 不得自动生成策略信号。

## 五、优先级排序

当前优先级：

1. Pandas / NumPy：数据质检；
2. 轻量自写指标：量价观察；
3. 周六股性研究：历史样本统计；
4. VectorBT：未来轻量回测候选；
5. Polars：未来数据量增大后评估；
6. cvxpy：未来组合风险概念学习；
7. Qlib / RD-Agent：远期研究平台观察；
8. FinRL / FinGPT / FinRobot：远期 AI Finance 观察。

## 六、当前结论

小工坊当前阶段不需要重型量化平台。

当前最适合的路线是：

- 用 Pandas / NumPy 做数据质检；
- 用人工复盘继续做主判断；
- 用轻量指标提升观察质量；
- 用周六股性研究沉淀历史样本；
- 等样本和问题足够清楚后，再评估是否引入 VectorBT 等工具。
